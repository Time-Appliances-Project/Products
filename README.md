# OCP-Compliant M.2 GNSS Module

The **OCP-Compliant M.2 GNSS Module** board is a compact GPS module based on the u-blox receiver, built to comply with the [OCP M.2 Sync Specification 1.1](https://www.opencompute.org/documents/m-2-sync-module-ocp-base-specification-1-1-pdf).

### 📌 Features

- M.2 2242 form factor
- Designed for use in PTP-capable systems
- Open source hardware design
- Comes in different types of receivers
  - Neo-M9N
  - ZED-F9T
  - ZED-F9P
